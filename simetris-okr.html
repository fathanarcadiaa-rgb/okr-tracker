Setup SIMETRIS Tracker

Hubungkan ke Google Sheets supaya semua device sync otomatis.

1
Buka script.google.com → New Project → paste isi file Code.gs → Save.
2
Klik Deploy → New Deployment → Type: Web App → Execute as: Me → Who has access: Anyone → Deploy.
3
Copy URL deployment yang muncul (format: https://script.google.com/macros/s/AKfy.../exec) → paste di bawah.
4
Klik Connect & Init. Tracker akan otomatis bikin sheet-sheet yang dibutuhkan.
Apps Script Deployment URL
URL ini disimpan di localStorage browser lo. Semua user lain yang mau connect juga perlu paste URL yang sama.
